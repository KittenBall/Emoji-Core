This addon is designed to display emojis in the game.

#### Addon features

*   Pure byte stream parsing, making it extremely fast.
*   Supports the display of all 3782 emojis from Unicode 16.0, including various variants, and is compatible with all known UNQUALIFIED or MINIMALLY\_QUALIFIED emojis.

#### Currently implemented features

*   The emojis you send will be replaced with shortcodes, such as :happy:. Therefore, people who have not installed the addon will no longer see garbled text if they do not have a font that supports emojis installed.
*   Emojis sent by others will be replaced with emoji images for display.
*   Shortcodes for emojis sent by others will be replaced with emoji images for display.
*   Chat bubbles display emojis.
*   Emoji auto complete
*   Support synonym suggestions.

#### Features under development

*   Management of emoji image packs. This will allow you to use different emoji image packs for replacement display.
*   Emoji keyboard.

#### Emoji Pack

*   Currently, the addon comes with an emoji image pack that uses [Google-Noto](https://github.com/googlefonts/noto-emoji), which supports up to Unicode 16.0.
*   In the future, emoji image packs from more different platforms will be added.
